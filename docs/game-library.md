# Browsing the Game Library

The [LewdPub game library](https://lewdpub.com/games) is the main catalog for exploring listed titles.

The catalog interface provides search and filtering tools. The visible controls include sorting options such as newest, most viewed, release date, top rated, and alphabetical order. Filters include game type, platform or file format, genre and tags, release year, and engine format.

## A practical browsing approach

Start with a search if you already know a title. Otherwise, narrow the catalog using the available filters, then change the sort order to compare newer or more popular entries.

Game listings can display information such as a title, version, file size, engine, tags, and a short description. Details may vary between entries.

The catalog is dynamic, so the number of games and the available filters can change. Use the live [All Games page](https://lewdpub.com/games) rather than relying on a saved copy of a listing.
