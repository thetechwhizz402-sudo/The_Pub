# Requesting a Game

LewdPub provides a [Request a Game page](https://lewdpub.com/request) where visitors can submit suggestions for titles they would like to see listed.

The public request form asks for the game title and platform. It also provides an optional field for additional details. The page describes a simple process: submit the information, allow the team to review it, and check for a notification if the request is acted on.

## Tips for submitting a useful request

Use the complete and correct game title. Include the relevant platform and add helpful identifying details when necessary, such as the developer name or a known version.

Submitting a request does not guarantee that a title will be added. For the current form and instructions, use the [official request page](https://lewdpub.com/request).
