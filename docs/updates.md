# Recently Updated Games

The [Updated Games page](https://lewdpub.com/updated-games) groups game listings by when updates were added. The public page uses day-based sections, making it easier to scan recent changes.

A listing may show its current version, approximate file size, engine, tags, description, and other metadata. These details help visitors distinguish an updated entry from an older version.

## Why the update page is useful

If you follow games that are still in development, the update page can help you identify titles that have received a newer build. It can also help returning visitors see what has changed since their last visit.

Update timing and listing information change frequently. For the latest entries, use the [official updated-games listing](https://lewdpub.com/updated-games).
