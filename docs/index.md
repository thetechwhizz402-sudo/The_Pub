# LewdPub: A Guide to the Website

This guide introduces the main areas of **[LewdPub](https://lewdpub.com/)**, an online catalog focused on adult-oriented PC games and related game listings.

Use the navigation to learn how the public catalog is organized, how to browse by engine or collection, where updated titles appear, and how the request and support pages work.

## Explore the main sections

- **[Game library](game-library.md):** browse and filter the catalog.
- **[Game discovery](game-discovery.md):** explore trending and highly rated listings.
- **[Updates](updates.md):** see titles grouped by recent update activity.
- **[Engines](engines.md):** browse games by development engine.
- **[Collections](collections.md):** explore curated groups of games.
- **[Requests](requests.md):** learn how to submit a game suggestion.

The official website is the authoritative source for current listings and availability: **[lewdpub.com](https://lewdpub.com/)**.
