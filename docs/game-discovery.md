# Discovering Games

LewdPub separates several discovery views so visitors can explore the catalog in different ways.

## Trending

The [Trending page](https://lewdpub.com/trending) provides a dedicated view of games attracting attention. It is useful when you want to explore titles that are currently drawing interest.

## Top-rated games

The [Top Games page](https://lewdpub.com/top-games) presents a ranked or rated discovery view. The page also exposes the catalog's sorting and filtering interface.

## Homepage highlights

The homepage features selected listings alongside latest games and other discovery areas. These sections offer another route into the catalog without requiring a specific search.

Rankings and popularity indicators are time-sensitive. Check the [live website](https://lewdpub.com/) for current results rather than treating examples or counts in this guide as permanent.
