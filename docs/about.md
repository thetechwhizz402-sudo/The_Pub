# About LewdPub

[LewdPub](https://lewdpub.com/) is a website centered on discovering and browsing adult-oriented games. Its public interface is organized around a searchable game catalog, discovery sections, engine groupings, collections, and recently updated listings.

The homepage highlights selected games and provides entry points to newer and recently updated titles. The navigation also links to dedicated pages for trending games, top-rated games, game requests, and game engines.

## What this guide covers

This repository documents the public-facing structure of the website. It is an independent guide, not an official announcement or a representation that the repository is operated by LewdPub.

For current information, visit the [official LewdPub website](https://lewdpub.com/) and its [About page](https://lewdpub.com/page/about).
