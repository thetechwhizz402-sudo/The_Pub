# LewdPub – Independent Website Guide

A multi-page, text-only guide to the public sections and navigation of [LewdPub](https://lewdpub.com/).

This repository is organized as a small documentation website. It explains how the site's public catalog is arranged, how visitors can discover games, and where to find the site's request, help, and policy pages.

> **Scope:** This is an independent informational guide. It is not the official LewdPub source code, does not host game files, and is not affiliated with game developers or publishers.

## Build the documentation site

This project uses MkDocs with the Material theme.

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

To build the static site:

```bash
mkdocs build
```

## Accuracy and maintenance

Website features and page paths can change. This guide describes the public website as reviewed on 8 November 2026. Always use the official website for current details.
